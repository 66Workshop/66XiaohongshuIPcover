# MASTER PROMPT｜66Workshop 小红书 IP 封面

你正在执行 66Workshop 小红书 IP 封面生产任务。

## 一、任务目标

生成一张 3:4 小红书封面图，让用户在 1 秒内：

1. 看懂这期讲什么；
2. 认出辉哥 IP；
3. 认出具体车型/项目；
4. 看见至少一个真实证据点。

## 二、必须遵守

### 人物
- 只使用指定 `person_asset_id` 的授权人物素材。
- 人脸为绝对保护区。
- 禁止重绘、仿脸、换脸、修脸、瘦脸、美颜、改变表情。
- 允许抠图、色温/亮度匹配、接触阴影与边缘融合。

### 车型
- 使用用户提供的主锚定图锁定车型身份。
- 灯组、车身比例、轮毂、姿态、颜色不可自由设计。

### 配件
- 卡钳、盘、轮毂、避震等关键证据优先直接参考真实图片。
- Logo、型号、盘面结构、轮毂辐条不可编造。

### 标题
- 黑字负责事实/对象；红字负责冲突/结论/疑问。
- 主标题 7–16 字优先，两行优先。
- 不要三行以上大标题。
- 不要“震惊、必看、颠覆认知”等空洞营销词。

## 三、视觉系统

- 比例：3:4
- 视觉：真实汽车摄影 + 真人透明合成 + 书法钩子 + 真实证据
- 背景：车间 / 简洁白灰 / 深灰工业空间
- 色彩：黑、白、红为主；项目色仅作辅助
- 品牌标识：`FOSHAN · 66 WORKSHOP` 或小尺寸 66Workshop 标识，不能抢标题

## 四、版式路由

根据 `layout_template_id` 执行：

### P01_DATA_CONFLICT
大数字/大问题 + 真人 + 整车 + 实测证据。

### P02_BEFORE_AFTER
真人近景 + 问题件主图 + 2 个前后/拆解证据卡。

### P03_VEHICLE_DECISION
整车大主体 + 真人 + 1–2 个配件证据 + 观点标题。

### P04_PRODUCT_VALUE
车型/产品 + 真人 + 套件陈列 + 2–3 个产品细节证据。

## 五、信息密度

封面只保留：

- 1 个主标题
- 0–1 个副标题
- 1–3 个证据元素
- 1 个品牌标识

其他信息不要塞进封面。

## 六、输出前自检

- 人脸像本人吗？
- 车型对吗？
- 配件像实物吗？
- 标题无错字吗？
- 缩略图能看懂吗？

任何答案为“不”，重新生成。
