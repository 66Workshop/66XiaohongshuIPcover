# 成功案例拆解｜V0.1

本文件把用户提供的 4 张已验证成功封面拆成可复用规则。目的不是模仿某一张，而是提炼“为什么它成立”。

## Case 01｜100公斤哪去了？

### 成立原因
- **钩子强**：数字 `100公斤` 足够具体，红字 `哪去了？` 直接制造信息缺口。
- **证据重**：大尺寸轮毂/刹车盘/卡钳和电子秤同时出现，不靠空口说减重。
- **人物位置合理**：真人在左下，承担“我来解释”的角色，不与标题抢主视觉。
- **车做背景身份锚点**：整车足够大，用户知道这不是泛汽车内容。

### 可复用规则
- 数据类标题优先 `大数字 + 大疑问`。
- 证据最好能“看见测量动作或测量结果”。
- 数据必须来源明确；不确定数字不能上封面。

### 对应模板
`P01_DATA_CONFLICT`

## Case 02｜洗干净了就修好？

### 成立原因
- **问题直白**：目标用户一眼知道这是维修/翻新判断题。
- **真人占比大**：人脸清楚，建立 IP 记忆。
- **主证据直接**：拆下来的原车卡钳/刹车部件就在人物旁边。
- **前后证据卡有效**：清洗后、拆解后两张小卡承担“证明”，不用写长解释。
- **白灰背景克制**：让红黑标题和红色卡钳成为重点。

### 可复用规则
- 修复/避坑内容优先 `表面动作 + 质疑`。
- 小证据卡最多 2–3 张。
- 修复类标题不宜再叠加大量品牌参数。

### 对应模板
`P02_BEFORE_AFTER`

---

## Case 03｜G500改刹车，先看为什么改

### 成立原因
- **车型大**：G500 本身就是内容入口，整车占画面核心。
- **人和车并列**：真人坐在右侧，既有 IP，又不挡车。
- **标题是观点，不是商品名**：核心是“为什么改”，更符合分享感。
- **配件证据充分**：底部实物卡 + 套件陈列让专业性成立。

### 可复用规则
- 车型内容先讲决策，不先讲“几活塞”。
- 车型必须保持年款、灯组、轮毂、姿态真实。
- 配件陈列只承担证据，不要把封面做成电商详情页。

### 对应模板
`P03_VEHICLE_DECISION`

---

## Case 04｜AP9561上梦想家值不值？

### 成立原因
- **产品名 + 车型 + 价值判断**，信息效率很高。
- 整车居中，真人在右侧，底部是整套产品陈列。
- 下方 3 张细节卡形成“产品证据带”。
- 黄色卡钳在黑色车身和深色车间里有高辨识度。

### 可复用规则
- 产品价值类封面可用 `型号 + 车型 + 值不值/怎么选`。
- 证据卡优先：卡钳细节、盘、装车轮毂效果。
- 商品元素多时，标题必须更少字。

### 对应模板
`P04_PRODUCT_VALUE`

# 四个案例的共同成功因子

## 1. 标题有真实矛盾
不是“专业升级”“性能提升”，而是：
- 数字去哪了？
- 洗干净是不是修好？
- 为什么要改？
- 到底值不值？

## 2. 每张图都有证据
- 实测秤
- 拆解前后
- 真实车辆
- 真实配件
- 装车效果

## 3. 真人不负责装酷，负责“判断”
人物姿势以解释、判断、坐姿为主，避免过度夸张、嚣张或营销式表情。

## 4. 黑红书法字只是钩子，不承担说明书任务
说明文字少而清楚，通常 1 行副标题足够。

## 5. 车型/配件色彩成为辅助视觉锚点
黄色/红色卡钳、白色 G500、黑色梦想家都可成为画面第二记忆点。

# 失败警告

如果后续生成只学到“黑红毛笔字 + 人 + 车 + 卡钳”，却没有：
- 真实冲突
- 真实证据
- 车型身份
- 人物身份

那只是学到了皮，不是工作流。
