# 资产授权与使用政策

## 1. 人物素材

仓库内登记的人物图像由 66Workshop 授权用于本项目的封面生产、内部测试、提示词/版式验证与工作流复用。

### 允许
- 作为封面合成主体
- 抠图、透明化
- 光影、色温、阴影融合
- 裁切与合理缩放

### 不允许
- 将人脸作为可自由生成的参考脸
- 换脸、仿脸、生成相似脸
- 改变五官、表情、脸型
- 将人物资产转授权给无关第三方

## 2. 字体/书法风格参考

仓库保存的是授权的**风格参考图**，用于约束黑红书法标题的视觉语言。

如果未来加入真实字体文件，必须单独记录字体授权范围。默认不把字体文件作为开源资源分发。

## 3. 成功案例

成功案例用于：
- 版式学习
- QA 对照
- 工作流回归测试
- 视觉一致性参考

不代表案例内所有第三方品牌、商标、车辆图像获得再授权。

## 4. 代码与资产分离

建议后续将：
- 规则/代码/JSON/Prompt 放 GitHub
- 大体积原始人物、视频、PSD 放对象存储
- GitHub 只保留 manifest、hash、预览图

## 5. 公开仓库提醒

当前仓库为公开仓库。任何提交到仓库的图片都可能被公开访问和下载。

如果后续加入未公开人物原片、客户隐私、车牌、VIN、手机号、订单、工位文件等，必须先脱敏或迁移到私有存储。
