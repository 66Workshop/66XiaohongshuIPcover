# QA_CHECKLIST — 66Workshop ChatGPT Cover Identity-Lock V0.1

## 1. QA 顺序

固定顺序，不允许因为“整体看起来很好”跳过前项：

1. 人物身份 Identity
2. 车型 Vehicle
3. 配件/证据 Product Evidence
4. 标题与文字 Typography
5. 版式 Layout
6. 66Workshop 品牌语言 Brand

P0 项（人物、车型、配件证据、标题事实）任一失败，候选图直接 FAIL。

---

## 2. Identity Gate｜人物身份一票否决

对照 `PERSON_IDENTITY_PRIMARY`，逐项检查：

- [ ] 整体脸型与脸宽/脸长比例一致
- [ ] 左右眼形状一致
- [ ] 眼距与眉眼距离一致
- [ ] 眉形、眉峰与眉尾位置一致
- [ ] 鼻梁、鼻头、鼻翼结构一致
- [ ] 嘴型、唇厚、嘴角结构一致
- [ ] 下巴长度与下颌线比例一致
- [ ] 发际线和主要发型身份特征一致
- [ ] 耳朵/鬓角等可见身份特征没有被任意改写
- [ ] 年龄感一致
- [ ] 肤色与本人基本一致
- [ ] 无明显磨皮、瘦脸、眼睛放大、鼻子收窄等“美颜换脸”现象
- [ ] 无“AI 明星脸/陌生帅哥脸”替代
- [ ] 如果路线要求保留原脸，脸部没有明显重新生成痕迹

### Identity 评分

- `IDENTITY_5`：源脸基本被保留；封面使用尺度下可认为是同一真人的高保真呈现
- `IDENTITY_4`：明确是本人，仅存在轻微非身份渲染差异
- `IDENTITY_3`：大概率是本人，但五官或脸型已有明显漂移 → FAIL
- `IDENTITY_2`：相似脸/替身感 → FAIL
- `IDENTITY_1`：明显是其他人 → FAIL

### 生产通过标准

必须同时满足：

- `IDENTITY_4` 或 `IDENTITY_5`
- 用户本人/授权人工确认 `identity_human_pass = true`

机器/模型自己的“看起来像”不能覆盖人工否决。

---

## 3. Vehicle Gate｜车型真实性

对照 `VEHICLE_EVIDENCE`：

- [ ] 车型/车系正确
- [ ] 年款关键特征没有漂移
- [ ] 前后灯组结构正确
- [ ] 前后保险杠/包围关键线条正确
- [ ] 车身比例和轴距视觉关系正常
- [ ] 轮毂造型与来源一致，若要求保留原轮毂则未替换
- [ ] 车身姿态没有被夸张到失真
- [ ] 品牌徽标/车型标识没有乱写
- [ ] 透视没有导致车与人物比例明显不合理

以下任一出现直接 FAIL：

- 生成成另一个车型
- 把不同年款的灯组/包围混在一起
- 用户要求保留的轮毂被生成成其他造型
- 关键品牌/车型标识错误

---

## 4. Product Evidence Gate｜配件真实性

对照 `PRODUCT_EVIDENCE`：

### 卡钳/刹车

- [ ] 卡钳主体轮廓可信
- [ ] 活塞/桥位/安装结构未出现明显不可能结构
- [ ] Logo 与型号文字没有凭空改变
- [ ] 碟盘纹路、盘帽、盘径视觉关系可信

### 轮毂

- [ ] 辐条数量与造型可信
- [ ] 中心盖/Logo 不乱写
- [ ] 与卡钳/碟盘空间关系合理

### 避震/底盘件

- [ ] 筒身/弹簧/支架结构没有明显穿模
- [ ] 不把不同产品结构混成一个不存在的产品

### 一票否决

- 假 Logo
- 假型号
- 明显错误产品结构
- 把“参考产品”变成另一个品牌/型号
- 用生成细节冒充真实测量/真实案例证据

如果证据不足：隐藏细节、缩小露出面积，或标记 UNKNOWN；禁止补造事实。

---

## 5. Typography Gate｜文字

- [ ] 主标题逐字正确
- [ ] 中文无错别字/乱码
- [ ] 英文品牌/型号大小写正确
- [ ] 数字、单位、尺寸没有被模型改写
- [ ] 主标题 1 秒可读
- [ ] 黑/白与红/黄层级明确
- [ ] 字体参考只影响视觉语言，不影响人物或车型

一票否决：

- 标题错字
- 产品型号错字
- 尺寸/价格/数据被擅自改写
- 未经确认的数据被做成确定事实

文字错误时优先局部修字，不得为了改一个字重新生成整张图并破坏已通过的人脸。

---

## 6. Layout Gate｜版式

- [ ] 3:4 比例成立
- [ ] 缩小到手机缩略图仍看得清主标题
- [ ] 人物是明确 IP，不被车/配件淹没
- [ ] 车型是第二主角时面积足够
- [ ] 证据图 1–3 个，不能堆满
- [ ] 人、车、配件有真实空间关系
- [ ] 无人物漂浮
- [ ] 无卡钳/轮毂/避震悬空
- [ ] 透视不夸张到像拼贴事故
- [ ] 没有廉价电商详情页感
- [ ] 没有九宫格参数 UI、小标签堆叠、夜店霓虹强 CG 感

---

## 7. Brand Gate｜66Workshop 视觉语言

- [ ] 黑/白/红为主，可少量黄强调
- [ ] 背景优先真实车间/摄影棚/深灰工业空间
- [ ] 视觉有判断感，不是“产品陈列照”
- [ ] `FOSHAN · 66 WORKSHOP` 如出现需克制且正确
- [ ] 人物、车、配件的真实性优先于视觉炫技

## 9. 红队规则

任何人都可以用下面一句话否决候选：

> “如果把标题和车都遮住，我还能在 1 秒内确认这就是本人吗？”

如果答案是“不确定”，身份不通过。
