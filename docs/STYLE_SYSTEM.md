# 66Workshop 小红书 IP 封面视觉系统 V0.1

## 1. 目标

封面不是单纯“漂亮”，而是同时满足：

**认人、认车、认主题、认观点。**

## 2. 固定视觉语言

### 主色
- 黑：主判断、背景压暗、工业感
- 白：留白、车型对比、标题底
- 红：冲突词、问号、结论词

### 辅助色
跟随项目证据使用，不额外发明：
- 黄色卡钳 → 黄作为局部强调
- 红色卡钳 → 红作为产品焦点
- 蓝色车身 → 作为车型身份色

## 3. 字体层级

### L1 主钩子
- 黑/红书法大字
- 1–2 行
- 占封面上部 25–40%
- 可有刷痕、飞白、墨点

### L2 副标题
- 清晰无衬线字体
- 车型 / 型号 / 实测类型
- 一行优先

### L3 证据标签
- 仅用于“清洗后 / 拆解后 / 实测 / 前后对比”
- 小红/黑标签
- 不要变成参数 UI

## 4. 人物比例

### 全身/坐姿
建议占画面 25–40%。

### 半身/近景
建议占画面 35–50%。

人物不是装饰，必须看得清脸。

## 5. 车与配件比例

- 车型决策类：整车 35–50%
- 产品价值类：产品证据 25–40%
- 数据实测类：测量证据可放大到 35–45%
- 修复类：问题件/拆解件 35–50%

## 6. 推荐构图

### A. 上标题 / 下场景
适合绝大多数封面。

### B. 左人物 / 右证据
适合修复、维修、观点。

### C. 中车 / 右人物 / 下配件
适合车型升级与产品值不值。

### D. 左人 / 中车 / 右大证据
适合实测、重量、刹车距离。

## 7. 空间规则

- 标题与人脸不得重叠
- 证据图不能切到只剩 Logo
- 车型不能被标题切掉关键灯组
- 人物脚部可裁，但脸与手势完整优先
- 最多 3 个主视觉层级

## 8. 禁区

- 毛玻璃 UI 堆叠
- 九宫格参数卡
- 太多小标签
- 过度发光、夜店霓虹
- 假车牌、乱码 Logo
- 真人脸 AI 重绘
- 卡钳漂浮、盘和轮毂不匹配

## 9. 66Workshop 品牌标识

优先使用标准英文：

`FOSHAN · 66 WORKSHOP`

品牌标识应弱于标题，通常放右上/左上或底部页脚。

## 10. 缩略图测试

封面生成后缩小到手机列表尺寸检查：

- 还能认出人吗？
- 还能看懂第一行标题吗？
- 车型身份还能认吗？
- 有证据点吗？

如果答案有两项“不”，封面失败。
